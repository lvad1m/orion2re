# Банк реплик дипломатии

> Часть [документа о локальной LLM](../README.md). Решение 20.11.2026 (раздел 13): «LLM офлайн —
> банк реплик». Статус: **данные готовы, движок их пока не читает.**

Готовые реплики лидеров для окна дипломатии: движок уже принял решение (отказать, объявить
войну, потребовать дань), реплика только произносит его голосом расы и характера. Банк нужен
для уровня B — машин без видеокарты или когда LLM не успевает: игрок всё равно слышит живую
речь, а не одну и ту же строку.

## Что внутри

| | |
|---|---|
| Рас | 13 (все стандартные расы MOO2) |
| Характеров | 6: xenophobic, ruthless, aggressive, erratic, honorable, pacifistic |
| Ситуаций | 18 (список — `BRIEF.md`) |
| Вариантов | 10 на ячейку и язык |
| Языков | русский и английский, написаны независимо, а не переводом |
| Строк | **28 080** (2 160 на расу), 3,2 МБ |

Файлы: `bank/<раса>.json`

```json
{"race": "sakkra",
 "lines": {"<характер>": {"<ситуация>": {"ru": ["…", "…"], "en": ["…", "…"]}}}}
```

Правила для каждой строки (подробно — `BRIEF.md`): одна-две фразы, обращение на «вы»/"you",
без имени расы собеседника, без ремарок и чисел; алфавит русского — только кириллица и знаки
(в игре его же держит `pattern` JSON-схемы), английского — только латиница. В `demand_tribute`
подстановка `{СУММА}` / `{AMOUNT}` ровно один раз; движок подставляет сумму **вместе с
валютой** («200 BC»), поэтому её ставят там, где падеж не важен.

## Проверка

```
python bank_build.py                 все расы: сводка, out/bank/lines.jsonl и review_<раса>.md для вычитки
python bank_build.py --race sakkra   одна раса с перечнем пометок
python wave2_tools.py show sakkra honorable    строки одного характера
```

Проверки (`textbank.py`, `flags_for`): отказ читается как отказ, согласие как согласие, в
войне есть «война», в мире — «мир» и т. д.; подстановка на месте; алфавит; длина; нет ремарок;
клаконы говорят «мы»; почти одинаковые варианты внутри ячейки.

## Состояние на 20.11.2026

- 28 080 строк, автоматических пометок — 0.
- **Повторов между расами нет.** После генерации нашлось 360 пар похожих строк у разных рас
  (пересечение слов больше 60 %), из них 17 полных дублей: писатели работали параллельно и не
  видели свежих строк друг друга. 281 строка переписана через `bank_build.py --apply-fixes`
  (каждая замена проверяется перед применением); `wave2_tools.py crossdupes` теперь находит 0 пар.

## Как сделано

- Пилот (псилоны и клаконы, 6 ситуаций) и первая волна — по 3 варианта на ячейку — написаны
  Claude Opus 5.5 (основной сеанс и по помощнику на расу), вторая волна до 10 вариантов —
  частично Claude Opus 5.5, остаток — Claude Sonnet 5.5 по тому же `BRIEF.md` и с теми же
  проверками. Всё — с раскрытием участия AI, как требует `CONTRIBUTING.md`.
- Тексты оригинальные: строки игры (`DIPLOMSG.LBX`) не цитировались и не пересказывались.
- `textbank.py` умеет и генерировать банк локальной моделью через llama.cpp (стенд
  `E:\AI\Scripts\bench`); на RTX 3050 Ti качество 4B-моделей для этого признано недостаточным.

## Как использовать в движке (предложение, не решение)

1. Ключ — (раса, характер, ситуация, язык); раса берётся из `STOCK_RACE`, для своей расы игрока —
   ближайшая по характеру или общий набор.
2. Вариант выбирать **не игровым** генератором случайных чисел (`game_random::Random` сдвинул бы
   поток и сломал повторы и сетевую игру), а отдельным генератором интерфейса; не повторять
   последние N показанных вариантов.
3. На уровне A живая LLM может дописывать к строке банка деталь из памяти (обида, недавняя
   война), на уровне B строка банка показывается как есть.
4. Когда формат будет утверждён, данные переедут к игровым в `data/base/…`.
