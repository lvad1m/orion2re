# Профиль железа: ноутбук с RTX 5070 Laptop (8 ГБ)

> Часть [документа о локальной LLM](../README.md). Состояние на 20.11.2026: ноутбук ещё не
> настроен, ниже — инструкция. Первый профиль и результаты бенчмарка —
> [RTX_3050_ti](../RTX_3050_ti/README.md), [бенчмарк 20.11.2026](../RTX_3050_ti/benchmark-2026-11-20.md).

## Зачем второй ноутбук

- **Офлайн-задачи** (решение 20.11.2026 в [README](../README.md), раздел 13): банк реплик и
  аналитик проигранных партий. Скорость там не важна, важно качество, поэтому берём самую
  сильную модель, какая влезет, — хоть на всю ночь. Первый кандидат — Qwen3.5-9B: на этом
  ноутбуке он уже показал себя хорошо, а Qwen3.5-4B из того же семейства дал лучший русский
  текст в бенчмарке на RTX 3050 Ti.
- **Проверка моделей тяжелее 4B** тем же стендом, что на RTX 3050 Ti: даёт ли 8B–14B заметно
  лучшие решения и тексты.
- **Второй класс машин игроков** (8 ГБ VRAM) для уровня A.

## Железо

Заполнить после шага 4 инструкции.

| Что | Значение |
|---|---|
| GPU | NVIDIA GeForce RTX 5070 Laptop GPU, 8 ГБ VRAM (Blackwell, sm_120) |
| Драйвер | ⏳ (`check-gpu.cmd` покажет версию и максимальную CUDA) |
| CPU | ⏳ |
| RAM | ⏳ — важно для MoE-моделей с экспертами в RAM |
| ОС | ⏳ |

## Установка

1. **Скопировать скрипты** с первого ноутбука (сами модели и сборку можно не копировать):
   - `E:\AI\llama.cpp\scripts\`, `E:\AI\llama.cpp\*.cmd`, `E:\AI\llama.cpp\config.txt`;
   - `E:\AI\Scripts\` целиком (без `bench\results\`, если не нужны старые ответы).

   Удобнее всего — те же пути `E:\AI\…`. Если диска `E:` нет, поправить две строки в начале
   `E:\AI\Scripts\models\catalog.ps1`:

   ```
   $LlamaBin  = 'E:\AI\llama.cpp\bin'
   $ModelsDir = 'E:\AI\llama.cpp\models'
   ```

   Остальные скрипты находят пути сами, от своей папки.

2. **Выбрать сборку CUDA 13.5.** В `E:\AI\llama.cpp\config.txt`:

   ```
   CUDA=13.5
   ```

   Карты Blackwell (sm_120) поддерживаются начиная с CUDA 12.8, поэтому сборка 12.4 с первого
   ноутбука здесь ненадёжна. В релизе b12535 есть `llama-b12535-bin-win-cuda-13.5-x64.zip`
   (219 МБ) и `cudart-llama-bin-win-cuda-13.5-x64.zip` (407 МБ).

3. **Установить:** `E:\AI\llama.cpp\install-or-update.cmd`. Скрипт скачает сборку и CUDA runtime,
   проверит SHA256 и положит всё в `bin`.

4. **Проверить:** `E:\AI\llama.cpp\check-gpu.cmd`. Скрипт сравнит версию CUDA сборки с
   максимальной, которую поддерживает драйвер, и покажет видеокарту в `llama-cli --list-devices`.
   Если драйвер старше CUDA 13.5 — обновить драйвер NVIDIA (это делаете вы сами) и повторить.
   Вписать драйвер, CPU и RAM в таблицу выше.

5. **Модели.** Либо скопировать `.gguf` из `E:\AI\llama.cpp\models` первого ноутбука (быстрее,
   ~15 ГБ без RPG-4B), либо скачать: `E:\AI\Scripts\download-<ключ>.cmd`. Тяжёлые модели
   добавляются в каталог (`catalog.ps1`) после подбора — см. ниже.

6. **Прогнать стенд** (тот же, что на RTX 3050 Ti):

   ```
   E:\AI\Scripts\bench.cmd --models qwen35-4b,qwen3-4b-2507
   E:\AI\Scripts\bench.cmd --suite v2 --out bench\results\<папка>-v2
   E:\AI\Scripts\bench.cmd --suite speed --cooldown 55 --out bench\results\<папка>-speed
   python E:\AI\Scripts\bench\report.py bench\results\<папка> bench\results\<папка>-v2 bench\results\<папка>-speed
   ```

   Те же 4B-модели дают прямое сравнение двух карт; затем — тяжёлые кандидаты, первым
   Qwen3.5-9B:

   ```
   E:\AI\Scripts\download-qwen35-9b.cmd
   E:\AI\Scripts\bench.cmd --models qwen35-4b,qwen35-9b
   E:\AI\Scripts\bench.cmd --models "qwen35-9b:reasoning=on;extra=--reasoning-budget 600;label=qwen35-9b-think"
   ```

   Пара `qwen35-4b` / `qwen35-9b` показывает, что даёт размер внутри одного семейства; третья
   строка — та же модель с бюджетом размышлений для редких важных решений.

## Что влезет в 8 ГБ

Оценка: файл модели + KV-кэш q8_0 на 8192 токена (~0,6 ГБ у моделей класса Qwen3-8B) +
~0,3 ГБ рабочих буферов + запас для Windows и игры.

| Класс | Файл Q4 | Как работает | Примеры |
|---|---:|---|---|
| 4B (как на RTX 3050 Ti) | 2,4–2,9 ГБ | целиком на GPU, много места под контекст и слоты | все модели первого бенчмарка |
| Плотные 8–9B | ~4,5–5,7 ГБ | **целиком на GPU** | **Qwen3.5-9B** Q4_K_M (5,7 ГБ, ключ `qwen35-9b`) — уже проверен на этом ноутбуке, хорошо рассуждает и в общих задачах, и в программировании; DnD-8B (на 3050 Ti — 8 ток/с с частью слоёв на CPU, здесь ожидаем в 3–4 раза быстрее) |
| Плотные 12–14B | ~7,5–9 ГБ | впритык: меньший квант (Q3/IQ4) или часть слоёв на CPU | ⏳ подобрать |
| MoE ~30B, ~3B активных | ~17–20 ГБ | общие слои на GPU, эксперты в RAM (`--n-cpu-moe`); нужна RAM от 32 ГБ | Qwen3.6-35B-A3B (README, раздел 8) |

Конкретные тяжёлые модели подбираются поиском перед загрузкой (что вышло, какие кванты, какой
русский) и добавляются в `catalog.ps1`.

## Настройки, которые уже известны по первому ноутбуку

- **`--fit-target`.** Стандартные 1024 МиБ на 4 ГБ выталкивали слои на CPU; `start-model.ps1` и
  стенд используют 256 МиБ. На 8 ГБ можно оставить 256, а если рядом запущена игра или
  браузер — поднять до 512 (`start-<ключ>.cmd -FitTarget 512`, `bench.cmd --fit-target 512`).
- **Размышления только с бюджетом.** Для рассуждающих моделей — `--reasoning-budget N`, иначе
  модель может думать тысячи токенов и не ответить (бенчмарк, раздел 3.7). DnD-8B игнорирует
  `--reasoning off`, ему нужен `--reasoning-budget 0`.
- **Нагрев.** Стенд с `--cooldown 55` перед каждой моделью ждёт, пока карта остынет, — иначе
  скорость моделей зависит от их порядка в прогоне.
