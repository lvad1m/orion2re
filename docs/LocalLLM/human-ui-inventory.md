# Human interface inventory for the new mechanics (survey 27.11.2026, read-only)

Branch feature/advisor-stage1. Paths are under `src/game/`. Row type: D = decision (a choice made for an empire), I = information (something that happens to the human or that the human should see).
"Today" = what a human empire gets now. Effort: S = hours, one existing screen/message type; M = a day or two, extend an existing screen; L = new screen or a protocol (multiplayer sync) change.

Common pattern (applies to almost every module): the module is flag-gated, acts only for `objectives != PLAYER_OBJECTIVE_HUMAN` (a local `Computer_()` helper copied into each .cpp), logs with `SDL_LogInfo` only, and keeps no message for the human. The human is still a TARGET of most of them (spied on, sabotaged, smeared, raided, stained) and learns nothing except the classic 1.40 messages. Only `stability.cpp:167` and `world_events.cpp:530` call `MSG_::Add_Msg` (a rebellion message, classic type). `news::Add` is called from 14 places and read only by `advisor_view.cpp` (LLM), never by a human screen.

## Choice popup (one piece, many modules)

All event-style modules (incidents, overtures, discoveries, pirate_world, moo_world, wanderers trader, crises) share one pattern: a record is created with an option chosen by `Choose(kind, player)` which returns 0 for a human, and `Start(..., option)` already accepts an explicit `option >= 0` (`incidents.h:159`, `overtures.h:114`, `pirate_world.h:162`, `discoveries.h:152`; `moo_world` and `crises` have only `Choose`/`Choose_Option`). A single popup (title, text, 2-3 labelled buttons) plus a "pending decision" queue would serve all of them. Existing parts to build it from: `fields::Get_List_Field` (`fields.h:557`, used in the council ruling dialog `council.cpp:752` with 2-3 items and a prompt), `GENDRAW::Confirmation_Box` (`gendraw.h:8`), `GENDRAW::Message_Box` (`gendraw.h:4`). The per-turn flow where a modal can be shown is the `Display_Report_Aux` chain (`report.cpp:339-366`), which already hosts modal decisions (`Has_Officer_For_Hire`, `Need_To_Set_Occupation_Policy`, `Set_Initial_Tech`).
