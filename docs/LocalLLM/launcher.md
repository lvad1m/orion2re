# Лаунчер и язык интерфейса

> Часть [документа о локальной LLM](README.md). Статус: **решено 20.11.2026, не реализовано.**
> Идея автора: лаунчер, как у фанатских дополнений HoMM III, где перед запуском выбирают язык,
> версию правил и силу новых механик.

## 1. Зачем

- Выбрать **язык** до запуска: оригинальные тексты (меню, LBX) и наши новые (реплики из банка,
  события, GNN) — на одном языке.
- Выбрать **правила**: классика, 1.50, «живые соперники» (советник и его механики).
- Настроить **силу механик** (шпионаж, дипломатия, интриги) ползунками, не открывая конфиг.
- Выбрать **моды** из `data/mods/*.zip`.

## 2. Что уже есть в движке

| Возможность | Где | Как использует лаунчер |
|---|---|---|
| `/game-dir <папка>` | `src/startup_options.cpp` | папка данных игры; русский — это отдельный переведённый набор (`E:\Games\MOO2\v1_31rus`), английский — `v1_31eng` |
| `/config <файл>` | там же | другой основной конфиг (обычно не нужен) |
| `user.cfg` поверх основного конфига | `src/config/config_loader.cpp:195` | **лаунчер пишет только `user.cfg`**; `orion2re.cfg` пользователя не трогается; «сбросить всё» = удалить один файл |
| Схема настроек | `specs/config/main.json5` | у каждого параметра — название, описание, тип, диапазон, группа, категория документации → форма строится из схемы, новые настройки появляются в лаунчере сами |
| Моды | `enable v150;` в конфиге | список модов и переключатели |
| Синхронизация в сети | группа `gameplay` (save + synchronize) | игровые параметры хост раздаёт сам; у клиента ползунки на партию не влияют |

Встроенная настройка `MOX::settings.language` знает только 5 языков оригинала (en, de, fr, es,
it); русская версия — это переведённые LBX с тем же кодом, поэтому язык оригинала выбирается
папкой данных, а не этой настройкой.

## 3. Как устроен

- **Отдельный исполняемый файл** `orion2re-launcher` в том же CMake, на SDL3 + Dear ImGui (обе
  библиотеки уже вендорены): Windows и Linux, без новых зависимостей.
- **Окно:** язык; версия правил (предустановка); ползунки механик; моды; кнопка «Своя настройка»
  с полным списком параметров из схемы, по категориям документации; «Старт».
- **«Старт»:** записать `user.cfg` → запустить `orion2re(.exe) /game-dir <папка>` → закрыться
  (или свернуться).
- **Конфиг, а не аргументы командной строки,** для настроек: значения сохраняются между запусками,
  лаунчер показывает текущие, игровые параметры уже попадают в сейв и в сетевую синхронизацию.
  Аргументы — только для выбора папки и для разовых запусков (тесты, turn oracle).
- **Где `user.cfg`:** в портативном режиме (Windows) — рядом с данными игры; в XDG-режиме (Linux) —
  в каталоге конфигурации пользователя (`user_paths`). Проверить порядок поиска при реализации.

## 4. Язык новых текстов

- Новая настройка `interface language = auto | en | ru` (группа `interface`, локальная).
  `auto` — по папке данных (`*rus*` → ru, иначе en).
- Её читают: банк реплик ([textbank](textbank/README.md), уже RU и EN), события, GNN, будущие
  сообщения советника игроку.
- Лаунчер выставляет её вместе с папкой данных, но её можно задать и отдельно (английские
  оригинальные тексты + русские новые).

## 5. Предустановки и ползунки

| Предустановка | Что пишет в `user.cfg` |
|---|---|
| Классика | `advisor enabled = false;` моды выключены |
| 1.50 | `enable v150;` советник выключен |
| Живые соперники | `advisor enabled = true;` механики советника включены, значения по умолчанию; `colony misc_costs spy = 60;` ([mechanics.md](mechanics.md), 3.2.6, рычаг 3) |
| Своя настройка | всё, что выбрано вручную |

| Ползунок | Параметры |
|---|---|
| Шпионаж | `advisor rules_spies`, `advisor spy_target_weight_percent` (100–1000 %), позже — механики шпионажа и контрразведки (mechanics.md 3.2) |
| Гибкость соперников | `advisor rules_objectives`, `advisor objective_min_turns`, `advisor rules_period` |
| Экспансия соперников | `advisor rules_expansion` (крюк экспансии, этап 2в) |
| Дипломатия, интриги, события | параметры механик этапов 6–7, по мере появления |

Каждая позиция ползунка — набор конкретных значений из схемы; «Своя настройка» показывает, что
именно он выставил.

## 6. Что сделать

1. Настройка `interface language` и выбор строк банка реплик по ней.
2. Цель CMake `orion2re-launcher`: окно, чтение и запись `user.cfg`, запуск игры.
3. Форма по схеме: использовать сгенерированные описания конфига (или читать `main.json5`) —
   выбрать при реализации.
4. Предустановки и ползунки как таблица в данных (не в коде), чтобы их могли менять моды.
5. Тесты: запись и чтение `user.cfg` (круговой тест), предустановки → ожидаемые значения.

   меньше файлов, но смена папки данных требует перезапуска.
