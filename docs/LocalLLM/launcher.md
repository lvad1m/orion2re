# Лаунчер и язык интерфейса

> Часть [документа о локальной LLM](README.md). Статус: **решено 20.11.2026, не реализовано.**
> Идея автора: лаунчер, как у фанатских дополнений HoMM III, где перед запуском выбирают язык,
> версию правил и силу новых механик.

## 1. Зачем

- Выбрать **язык** до запуска: оригинальные тексты (меню, LBX) и наши новые (реплики из банка,
  события, GNN) — на одном языке.
- Выбрать **правила**: классика, 1.50, «живые соперники» (советник и его механики).
- Настроить **силу механик** (шпионаж, дипломатия, интриги) ползунками, не открывая конфиг.
- Выбрать **моды** из `data/mods/*.zip`.

## 2. Что уже есть в движке

| Возможность | Где | Как использует лаунчер |
|---|---|---|
| `/game-dir <папка>` | `src/startup_options.cpp` | папка данных игры; русский — это отдельный переведённый набор (`E:\Games\MOO2\v1_31rus`), английский — `v1_31eng` |
| `/config <файл>` | там же | другой основной конфиг (обычно не нужен) |
| `user.cfg` поверх основного конфига | `src/config/config_loader.cpp:195` | **лаунчер пишет только `user.cfg`**; `orion2re.cfg` пользователя не трогается; «сбросить всё» = удалить один файл |
| Схема настроек | `specs/config/main.json5` | у каждого параметра — название, описание, тип, диапазон, группа, категория документации → форма строится из схемы, новые настройки появляются в лаунчере сами |
| Моды | `enable v150;` в конфиге | список модов и переключатели |
| Синхронизация в сети | группа `gameplay` (save + synchronize) | игровые параметры хост раздаёт сам; у клиента ползунки на партию не влияют |

Встроенная настройка `MOX::settings.language` знает только 5 языков оригинала (en, de, fr, es,
it); русская версия — это переведённые LBX с тем же кодом, поэтому язык оригинала выбирается
папкой данных, а не этой настройкой.

## 3. Как устроен

- **Отдельный исполняемый файл** `orion2re-launcher` в том же CMake, на SDL3 + Dear ImGui (обе
  библиотеки уже вендорены): Windows и Linux, без новых зависимостей.
- **Окно:** язык; версия правил (предустановка); ползунки механик; моды; кнопка «Своя настройка»
  с полным списком параметров из схемы, по категориям документации; «Старт».
- **«Старт»:** записать `user.cfg` → запустить `orion2re(.exe) /game-dir <папка>` → закрыться
  (или свернуться).
- **Конфиг, а не аргументы командной строки,** для настроек: значения сохраняются между запусками,
  лаунчер показывает текущие, игровые параметры уже попадают в сейв и в сетевую синхронизацию.
  Аргументы — только для выбора папки и для разовых запусков (тесты, turn oracle).
- **Где `user.cfg`:** в портативном режиме (Windows) — рядом с данными игры; в XDG-режиме (Linux) —
  в каталоге конфигурации пользователя (`user_paths`). Проверить порядок поиска при реализации.

## 4. Язык новых текстов

- Настройка `interface language = en | ru` (группа `interface`, перечисление `text_language`, по умолчанию `en`).
  **Сделано 28.11.2026 (часть 1, тексты игры):** `en` — оригинальные файлы, ничего не меняется. `ru` — каждый
  оригинальный LBX из таблицы (`src/game/text_language.cpp`: `estrings` → `estrruss`, `fonts` → `fntsr` и ещё 23)
  открывается как русский двойник, если он есть в папке игры; иначе молча оригинал. Подмена стоит в
  `vfs::fopen_lbx` (имя для `<имя>/NNN` и для целого файла) и в `string_overrides` (имя sidecar `.json5` и
  файла, с которым сравнивается приоритет), так что английские sidecar и оверрайды записей (например
  `estrings.json5` из v150) русский текст не затирают, а русская правка — sidecar двойника (`estrruss.json5`).
  В sidecar двойника русский пишется обычным UTF-8 и сохраняется в CP866
  (`text_language::From_Utf8`, `Decode_Bytes`). Читается при старте, смена требует перезапуска.
  Режима `auto` пока нет (по папке данных; решит лаунчер).
- **Файлы наших текстов (28.11.2026, часть 2).** `data/base/texts/<язык>.json5` (в `base.zip` вместе с остальным
  `data/base`; путь в VFS `texts/<язык>.json5`). Вложенные объекты, ключ текста - путь через точку
  (`choices.incidents.painless.title`), значения - обычные строки UTF-8, подстановки `{имя}` (игра заполняет их
  через `texts::Format`, форматов printf в файлах нет; неизвестная подстановка остаётся как написана, порядок в
  переводе можно менять). `texts::Get(ключ)`: текст текущего языка, иначе английский, иначе сам ключ (одна строка
  в журнале на ключ). Английский хранится как есть, русский при чтении переводится в CP866
  (`text_language::From_Utf8`); поэтому в русских строках только русские буквы, ASCII и псевдографика.
  Читается один раз при старте (`texts::Load` в `main.cpp`), смена языка требует перезапуска. Битый файл даёт
  одну строку-предупреждение и пропускается, игра идёт на английском.
  **Как добавить язык или поправить текст:** мод кладёт свой `data/texts/<язык>.json5` (поддержаны `en` и `ru`;
  ключи верхнего слоя перекрывают нижний). Новый язык (например `de`) требует ещё значения в
  `text_language::e_language` и в настройке `interface language`.
- Её читают: банк реплик ([textbank](textbank/README.md), уже RU и EN), события, GNN, будущие
  сообщения советника игроку.
- Лаунчер выставляет её вместе с папкой данных, но её можно задать и отдельно (английские
  оригинальные тексты + русские новые).

## 5. Предустановки и ползунки

| Предустановка | Что пишет в `user.cfg` |
|---|---|
| Классика | `advisor enabled = false;` моды выключены |
| 1.50 | `enable v150;` советник выключен |
| Живые соперники | `advisor enabled = true;` все механики советника включены, значения по умолчанию (цели, разведсеть, экспансия, разведка карты в начале партии, Ланчестер, коалиция, контр-дизайн, память боёв, византийская доктрина; аванпосты выключены — в долгой игре вредят); `ai research_uses_own_output = true;` (исправление ошибки оригинала в выборе исследований ИИ); `colony misc_costs spy = 60;` ([mechanics.md](mechanics.md), 3.2.6, рычаг 3); `diplomacy memory = true;` (дипломатическая память, mechanics.md 4.1: на стенде 400 ходов войны кончаются раньше, галактика растёт сильнее — README 10.4.4); `advisor rules_phases = true;` (игра на победу, README 10.7: лидер завоёвывает слабых по одному, все поднимаются против претендента на 2/3 голосов совета, коалиционная война; решение автора 21.11.2026 — на стенде против обычного ИИ выигрыша нет, смысл — партия против человека, README 10.4.8) |
| Своя настройка | всё, что выбрано вручную |

| Ползунок | Параметры |
|---|---|
| Шпионаж | `advisor rules_spies`, `advisor spy_target_weight_percent` (100–1000 %), позже — механики шпионажа и контрразведки (mechanics.md 3.2) |
| Гибкость соперников | `advisor rules_objectives`, `advisor objective_min_turns`, `advisor rules_period`; флажок «соперники приспосабливаются» включает и `rules_exploration`, `rules_lanchester`, `rules_counter_design`, `rules_seen_ships` (память боёв) |
| Экспансия соперников | `advisor rules_expansion` (крюк экспансии, этап 2в) |
| Игра на победу | `advisor rules_phases` (флажок в блоке советника; части — `advisor phase_parts`) |
| Дипломатия, интриги, события | `diplomacy memory` (флажок «Дипломатическая память»; меняет поведение всех компьютерных империй, поэтому не зависит от флажка советника), дальше — параметры механик этапов 6–7, по мере появления |

Каждая позиция ползунка — набор конкретных значений из схемы; «Своя настройка» показывает, что
именно он выставил.

## 6а. Русский язык: что выяснилось 28.11.2026

- **Движок в `v1_31rus` показывает английский.** Русский выпуск 1.31 кладёт тексты и шрифт в отдельные
  файлы (`JIMTXTR.LBX` для `JIMTEXT.LBX`, `FNTSR.LBX` для `FONTS.LBX` и ещё 23), их грузил свой
  `MOO2_RUS.EXE`. orion2re открывает оригинальные имена, а `language.ini` в папке нет (язык 0).
- **Мод `rus` из файлов установки.** Скрипт `out/advisor-work/run/make_rus_mod.py` собирает
  `data/mods/rus.zip`: каждый оригинальный файл заменяется русским двойником целиком (VFS, `data/<имя>.LBX`).
  Данные игры не попадают в репозиторий. 18 файлов подходят без изменений: русские записи того же размера
  (диалоги, дипломатия, события, совет, подсказки, лидеры, имена кораблей и звёзд, описания технологий,
  шрифт). Игра с `enable rus;` загружается до главного меню.
- **Не подходят шесть таблиц строк** (`HESTRNGS`, `ESTRINGS`, `RSTRING0`, `TECHNAME`, `RACESTUF`, `CREDITS`):
  русские записи длиннее, движок отказывает («incorrect record size»). Нужна поддержка в движке (принять
  русский размер записи) или перенос в строковые оверрайды; пока они английские.
- **Картинки с текстом** (кнопки главного меню, «SELECT RACE») русский выпуск не переводил, они английские.
- **Сделано 28.11.2026 (часть 1).** Настройка `interface language` и таблица двойников (раздел 4). Три таблицы
  строк с длиннее записью (`ESTRINGS` 23465, `HESTRNGS` 14424, `RSTRING0` 7131 байт) принимаются со своим
  размером записи (`string_overrides::Load_String_Table`): достаточно строк (812, 397, 177), иначе двойник
  отключается до конца запуска с записью в журнале и читается оригинал. `TECHNAME`, `RACESTUF`, `CREDITS`
  грузятся как сырые таблицы или по числу записей и принимают русский размер без изменений. Кнопки и картинки
  остаются английскими. Тесты: `test_text_language`, `test_farload_buffer_vfs`.
- **Кодировка.** Русские строки набраны в CP866 и показываются шрифтом `FNTSR`. Поэтому наши новые русские
  тексты видны только вместе с модом `rus`; язык новых текстов следует за ним (`interface language`).
